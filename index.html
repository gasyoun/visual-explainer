02 · как это работает

Spec → build → check

01

spec.json

Аудитория, тезис, биты, данные. Один JSON, который читает человек и машина.

02

build.py

Собирает один HTML: inline CSS и JS, данные из committed JSON, никаких сборщиков.

03

check.py + render.py

Проверяет trust-блок, ссылки, mobile и внешний JS; рендерит desktop и mobile PNG для ревью.

python tools/build.py examples/token-tax/spec.json
